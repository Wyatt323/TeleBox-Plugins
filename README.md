# TeleBox-Plugins

## 添加插件仓库

在 TeleBox 聊天中发送：

```text
.tpm source add https://github.com/Wyatt323/TeleBox-Plugins
```

查看当前自定义源：

```text
.tpm source
```

## 插件功能

| 安装名 | 命令 | 功能简介 |
| --- | --- | --- |
| `tj` | `.tj` | 统计指定消息的全部回复，列出回复用户、时间和消息内容。 |
| `aix` | `.aix` | AI 对话、绘图、模型与提示词等 AI 功能。 |
| `stsave` | `.stsave` / `.st` | 保存贴纸，或将回复的图片、视频等媒体转换后保存到贴纸包。 |
| `yvlux` | `.yvlux` | 根据消息生成语录贴纸，并支持保存到贴纸包。 |

## 安装插件

```text
.tpm i tj
.tpm i aix
.tpm i stsave
.tpm i yvlux
```

## 更新插件

```text
.tpm update
```
